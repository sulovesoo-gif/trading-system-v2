# Meeting - 2026-07-30-01

## 회의 목적

SK하이닉스 SMA 크로스 알림의 기본 전송 경로를 ntfy로 전환하고, Ubuntu 테스트 서버에서 주문·신호 이력과 분리된 연결 테스트를 수행한다.

## 논의 내용

- SMTP 구현은 삭제하지 않고 비활성 대안으로 유지한다.
- 기본 알림 경로는 ntfy 토픽 기반 푸시 알림으로 사용한다.
- 연결 테스트는 별도 스모크 스크립트로 수행하여 SMA 신호, 주문, `analysis_signal_notification` 이력을 생성하지 않는다.

## 결정사항

- ntfy가 활성화되면 SMA 알림 실행기는 SMTP보다 ntfy를 우선 사용한다.
- ntfy 설정은 서버 `.env`의 활성화 여부, 기본 URL, 토픽, 우선순위로 관리한다.
- 테스트 메시지는 제목 `Trading System V2 테스트`와 주문 비실행 안내 본문으로 1회 전송한다.
- ntfy 서버의 테스트 메시지 수락은 완료했으며, 수신 기기 표시 여부는 별도로 확인한다.

## 보류사항

- 수신 기기에서의 실제 푸시 표시 확인
- 테스트 DB의 SMA 분석·성과·알림 이력 DDL 적용
- 본장 중 UN 완료 1분봉 기반 신호와 ntfy 알림 전용 스모크
- SMTP 실제 발송 검증
