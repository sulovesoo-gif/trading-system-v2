- SK하이닉스는 `000660 / UN / INTEGRATED` 완료 1분봉 종가를 SMA5·SMA10 주 시계열로 사용한다. KRX·NXT 원본은 비교용 RAW로 별도 보존한다.

## 결정사항

- 주식·ETF 6종 KRX 1분봉 백필을 완료했다.
- `job_id=2`, 258개 세그먼트, 96,927행을 기록했으며 중복·실패는 0건이다.
- 원격 서버는 OpenSSH `trading-v2` 별칭으로 Codex가 직접 작업한다.
- SK하이닉스 타점 기준은 `000660 / UN / INTEGRATED` 완료 1분봉이다.
- SMA5·SMA10은 완료 1분봉 종가로 Analysis 계층에서 계산한다.
- SMA 크로스와 종가의 SMA10 돌파가 동시에 발생해야 후보 타점이다.
- 직전 확정 타점 이후 방향과 무관하게 종가가 ±1% 이상 움직여야 확정한다.
- 후보 생성 후 ±1% 경계 종가 돌파 시 새 크로스 없이 기존 방향으로 확정할 수 있다.
- 크로스 방향과 해당 1분봉 방향의 일치 여부를 `ALIGNED` / `OPPOSED` / `NEUTRAL`로 기록한다.
- 레버리지·인버스는 신호 차단 조건이 아니라 비교 관측값으로 기록한다.
- 실제 주문은 구현하지 않고 이메일 알림만 사용한다.
- KRX·NXT·UN 원본은 별도 RAW로 보존한다.
- UN 통합 시세의 장전·본장·장후 특성은 다음 거래일에 추가 검증한다.
